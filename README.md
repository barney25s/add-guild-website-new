# ADD: Growtopia Guild Website (flat version)
All files sit in one folder, so uploading to GitHub is just: select all files, drag, commit.

- Edit content in `config.js` (Discord link, rules, rewards, text).
- Replace `mascot.png` to change the mascot.
- Colors: variables at the top of `styles.css`.

Run locally: `npm install` then `npm run dev`.
Deploy on Render: New + > Blueprint > pick the repo (uses render.yaml: Node web service running server.js).
